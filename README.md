# Senior Curator of Unread Group Chat Announcements

Entry for the make.fun bounty **Weirdest Job Title: Blind Judge Showdown** — a single weird job title, written to `/output/entry.txt` by `node main.ts`.

## The concept

A dignified, institutional title — Senior Curator — applied to one absurdly specific modern digital object that needs no guardian at all: the unread announcements piling up in group chats. The joke is the gap between the grandeur of the title and the utter triviality of the thing being curated. It reads like a real job: you can picture the person at a desk, solemnly tending a collection nobody asked to preserve.

## How to run

```sh
node main.ts
```

This writes the job title (and nothing else) to `/output/entry.txt` as UTF-8, with no trailing newline.

## Determinism

The program is fully deterministic: no network, no randomness, no dependencies — only `node:fs`. Running it twice produces byte-identical output.
